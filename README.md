# 🚀 Plantillas SEO: robots.txt & llm.txt para CMS

Este repositorio contiene configuraciones estándar y optimizadas para **SEO Técnico** y **AI Optimization (AIO)**. 

Incluye archivos listos para usar en:
- WordPress
- Shopify
- PrestaShop

## 📂 ¿Qué incluye?

### 1. Robots.txt
Reglas de bloqueo estándar para evitar problemas de indexación y ahorrar *Crawl Budget* en las secciones administrativas de cada CMS.

### 2. llm.txt (Nuevo Estándar AI)
Plantillas de Markdown para ayudar a los **Large Language Models (LLMs)** como ChatGPT y Claude a entender mejor la estructura de tu web y a mejorar la visibilidad en búsquedas por IA.

---

## 🛠️ ¿Cómo implementarlo?

1. Descarga el archivo correspondiente a tu CMS.
2. Modifica la línea `Sitemap` con tu dominio.
3. Súbelo a la raíz de tu servidor (public_html).

> **⚠️ Importante:** Antes de subir cualquier archivo, haz una copia de seguridad de tu configuración actual.
